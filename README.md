---------------------------------------
--- README – Gestionale Spese e Budget
---------------------------------------
1. Descrizione del progetto
Il progetto consiste nella realizzazione di un'applicazione gestionale per la registrazione e il monitoraggio delle spese personali e la gestione dei budget mensili suddivisi per categoria.
Il programma consente di registrare le spese, consultare i dati inseriti e confrontare gli importi spesi con i budget definiti.

2. Requisiti per l'esecuzione
Per eseguire il programma sono necessari:
- Linguaggio di programmazione: Python 3.
- Interprete necessario: Python 3.12 o versione successiva.
- Database: SQLite
- Librerie utilizzate: `sqlite3`, datetime` 
  
3. Istruzioni per l'esecuzione
 3.1 Installazione dei requisiti
  Verificare che Python sia installato sul computer.
  Per controllare la versione installata, eseguire dal terminale: python --version

 3.2 Compilazione
  Non è richiesta alcuna fase di compilazione, in quanto Python è un linguaggio interpretato.

 3.3 Avvio del programma
  1. Aprire il terminale o il prompt dei comandi.
  2. Posizionarsi nella cartella contenente i file del progetto 'main.py'.
  3. Eseguire il seguente comando: "python main.py" (oppure anche "py main.py")
  Il programma verrà avviato e mostrerà il menu principale, dal quale sarà possibile accedere alle funzionalità disponibili.

Per uscire dal programma selezionare l'opzione "5"
